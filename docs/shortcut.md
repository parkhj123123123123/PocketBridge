# iPhone 단축어 만들기

PocketBridge는 iPhone의 **단축어** 앱과 공유 시트를 사용합니다. 따라서 iPhone 앱 설치, Mac, Xcode, Apple Developer 유료 계정이 필요 없습니다. Apple은 단축어가 공유 시트에서 파일과 미디어를 입력으로 받도록 설정할 수 있고, `URL 콘텐츠 가져오기` 동작이 POST 요청의 파일 본문을 보낼 수 있다고 안내합니다. [공유 시트 입력](https://support.apple.com/en-au/guide/shortcuts/apd7644168e1/ios), [POST 파일 본문](https://support.apple.com/en-au/guide/shortcuts/apd58d46713f/ios)을 참고하세요.

## 한 번만 설정하기

1. iPhone에서 **단축어** 앱을 열고 `+`를 눌러 이름을 `PocketBridge`로 만듭니다.
2. 단축어 상세 설정에서 **공유 시트에 표시**를 켜고, 허용 항목을 **미디어**와 **파일**로 설정합니다.
3. 아래 동작을 순서대로 추가합니다. 동작 이름은 iOS 버전에 따라 약간 다를 수 있습니다.

### 연결 정보 읽기

1. **QR 또는 바코드 스캔** → 결과를 `QR`로 저장합니다.
2. **입력에서 사전 가져오기** → 입력: `QR` → 결과: `연결`.
3. **사전 값 가져오기**를 세 번 추가하여 `연결`의 `server`, `room`, `token` 값을 각각 저장합니다.

Windows의 QR 대신 **연결 정보 복사**를 사용했다면, `클립보드 가져오기`를 첫 동작으로 넣고 그 결과를 `입력에서 사전 가져오기`에 연결합니다.

### 각 파일 보내기

4. **각 항목 반복** → 반복할 항목: `단축어 입력`.
5. 반복 안에 **파일 세부사항 가져오기**를 두 번 넣습니다. 첫 번째는 세부사항을 **이름**으로, 두 번째는 **파일 크기**로 설정합니다. 이어서 **해시 생성**을 넣고 `SHA-256`과 반복 항목을 선택합니다. 이 값들은 각각 `이름`, `원본 크기`, `원본 SHA-256`으로 둡니다.
6. **메뉴에서 선택**을 넣고 `원본 전송`과 `문서 압축`을 만듭니다. 두 메뉴 항목 아래의 빈 공간에 다음 동작을 넣습니다.
   - `원본 전송` 아래에서 **변수 설정**을 추가합니다. 변수 이름은 `전송 파일`, 값은 파란 변수 버튼에서 **반복 항목**을 선택합니다. **텍스트** 동작을 추가해 `none`을 입력하고, 그 결과를 다시 **변수 설정**으로 `압축`에 저장합니다.
   - `문서 압축` 아래에서 **아카이브 만들기**(iOS 버전에 따라 `아카이브 생성`)를 추가하고 입력으로 **반복 항목** 하나를 선택합니다. 다음에 **변수 설정**으로 결과 ZIP을 `전송 파일`에 저장합니다. **텍스트** 동작에 `zip`을 입력하고, 결과를 **변수 설정**으로 `압축`에 저장합니다.
   - 메뉴가 끝나는 지점 아래에서 다음 단계로 진행합니다. 사진·동영상은 이미 압축되어 있으므로 원본 전송을 선택하세요.
7. **Base64 인코드**에 `이름`을 넣어 `이름64`를 만듭니다. **파일 세부사항 가져오기**를 한 번 더 넣고 세부사항을 **파일 크기**, 입력을 `전송 파일`로 설정해 `전송 크기`를 만듭니다.
8. **텍스트** 동작을 추가하고, 파란 변수 버튼으로 `server`와 `room`을 끼워 다음 주소를 만듭니다. 이어서 **URL** 동작을 추가해 이 텍스트를 URL 값으로 변환합니다. QR에서 읽은 값이 서식 있는 텍스트로 처리될 때 발생하는 “리치 텍스트를 URL로 변환” 오류를 막는 단계입니다.

   ```text
   [server]/api/shortcut/[room]/upload
   ```

9. **URL 콘텐츠 가져오기**를 추가합니다.
   - URL: 바로 앞 **URL** 동작의 결과
   - 방법: `POST`
   - 헤더:

| 이름 | 값 |
| --- | --- |
| `Authorization` | `Bearer ` + `token` |
| `Content-Type` | `application/octet-stream` |
| `X-PocketBridge-Name64` | `이름64` |
| `X-PocketBridge-Original-Size` | `원본 크기` |
| `X-PocketBridge-Payload-Size` | `전송 크기` |
| `X-PocketBridge-Compression` | `압축` |
| `X-PocketBridge-SHA256` | `원본 SHA-256` |

   - 요청 본문: **파일**, 값: `전송 파일`
10. 반복 뒤에 **알림 표시**를 넣어 `PocketBridge 전송 완료`를 표시합니다.

## 보내는 방법

1. Windows 앱에서 서버 주소와 저장 폴더를 정한 뒤 **연결 QR 만들기**를 누릅니다.
2. 사진 앱 또는 파일 앱에서 파일을 선택하고 **공유 → PocketBridge**를 누릅니다.
3. 카메라 접근을 허용하고 Windows QR을 스캔합니다.
4. 각 파일에서 원본 또는 문서 압축을 고릅니다. 업로드가 끝날 때까지 단축어를 닫거나 iPhone을 잠그지 않습니다.

QR과 복사한 연결 정보에는 일회용 전송 토큰이 들어 있습니다. 다른 사람에게 보내지 말고, 전송이 끝나면 Windows 앱에서 **종료**를 누르세요. QR은 10분 뒤 만료됩니다.

## 압축과 한계

`문서 압축`은 ZIP 하나에 원본 파일 하나만 넣습니다. Windows는 ZIP을 풀어 원본 이름·크기·SHA-256을 다시 확인합니다. ZIP이 원본보다 작지 않으면 `원본 전송`을 선택하는 편이 빠릅니다.

단축어와 iOS가 지원하는 공유 가능한 파일만 보낼 수 있습니다. iCloud에만 있는 대용량 항목은 먼저 기기에 내려받아야 합니다. iOS의 메모리·자동화 제한은 기기와 iOS 버전에 따라 다르므로 대용량 동영상은 한 번에 하나씩 보내는 것을 권장합니다.

완성한 단축어는 iCloud 링크나 파일로 공유할 수도 있습니다. [Apple의 단축어 공유 안내](https://support.apple.com/guide/shortcuts/share-shortcuts-apdf01f8c054/ios)를 참고하세요.
